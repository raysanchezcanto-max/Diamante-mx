# Diamante MX

Dashboard de béisbol con marcadores, posiciones y líderes.

## Fase 1
- MLB: juegos del día
- MLB: tabla de posiciones
- MLB: líderes de AVG, HR y Hits
- Pestañas preparadas para LMB y LMP

## Desarrollo local
Requiere Node.js 20.9 o superior.

```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## Despliegue
Importar el repositorio en Vercel. Next.js será detectado automáticamente.
